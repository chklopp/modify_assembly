# modify_assembly.py - Command Examples

This file demonstrates all available commands in the modify_assembly.py script with before/after FASTA content and command file contents.

## reverse_complement
**Command:** `reverse_complement seq1`
**Description:** Reverse complement the given sequence
**Original FASTA:**
```
>seq1
AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA
>seq2
CCCCCCNCCCCCCCCCCCCCCCCCCCCNNNCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCCC
```
**Result FASTA:**
```
>seq1
TTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTTT
>seq2
CCCCCCNCCCCCCCCCCCCCCCCCCCCNNNCCCCCCCCCCCCCCCCCCCCCCCCCCCCCC
CCCC
```
**Command File Content:**
```
reverse_complement seq1
```
